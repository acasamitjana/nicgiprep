● Here's a structured breakdown of the linear_registration.py script:

  ---
  Overview

  This script runs the USLR linear registration step of a neuroimaging pipeline.
   Given a longitudinal BIDS dataset (multiple MRI sessions per subject), it
  rigidly aligns all timepoints into a common subject-specific template space,
  optionally also registering to MNI.

  ---
  CLI Arguments

  ┌─────────────┬──────────────────────────────────────────────────────┐
  │  Argument   │                     Description                      │
  ├─────────────┼──────────────────────────────────────────────────────┤
  │ --bids      │ Path to BIDS rawdata root (defaults to env BIDS_DIR) │
  ├─────────────┼──────────────────────────────────────────────────────┤
  │ --subjects  │ Optional list of subjects to process                 │
  ├─────────────┼──────────────────────────────────────────────────────┤
  │ --num_cores │ Parallelism via joblib                               │
  ├─────────────┼──────────────────────────────────────────────────────┤
  │ --force     │ Overwrite existing outputs                           │
  ├─────────────┼──────────────────────────────────────────────────────┤
  │ --reg_MNI   │ Also register the subject template to MNI space      │
  └─────────────┴──────────────────────────────────────────────────────┘

  ---

  ---
  Sequential Steps

  0. Setup (script level)

  - Parse args, load/cache BIDS database (.db file), attach preproc and uslr-lin
   derivative paths.
  - Instantiate USLR_Linear(bids_loader, subject_list).

  ---
  1. Per-subject: state check — _check_running_subject

  Determines which processing stage to (re)start from:

  ┌───────────┬──────────────────────────┬───────────────────────────────────┐
  │ exit_code │        Condition         │              Action               │
  ├───────────┼──────────────────────────┼───────────────────────────────────┤
  │ -1        │ Missing segmentations or │ Skip subject (error)              │
  │           │  NaN                     │                                   │
  ├───────────┼──────────────────────────┼───────────────────────────────────┤
  │ 1         │ 0 timepoints, or already │ Skip                              │
  │           │  fully done              │                                   │
  ├───────────┼──────────────────────────┼───────────────────────────────────┤
  │ 5         │ Exactly 1 timepoint      │ Symlink/copy files as template,   │
  │           │                          │ no registration needed            │
  ├───────────┼──────────────────────────┼───────────────────────────────────┤
  │ 0         │ Ready to run from        │ Full pipeline                     │
  │           │ scratch                  │                                   │
  ├───────────┼──────────────────────────┼───────────────────────────────────┤
  │ 2         │ Graph done,              │ Resume from step 4                │
  │           │ template/eTIV missing    │                                   │
  ├───────────┼──────────────────────────┼───────────────────────────────────┤
  │ 3         │ Graph + template done,   │ Resume from step 5                │
  │           │ eTIV missing             │                                   │
  ├───────────┼──────────────────────────┼───────────────────────────────────┤
  │ 4         │ All done except MNI      │ Resume from step 6                │
  │           │ registration             │                                   │
  └───────────┴──────────────────────────┴───────────────────────────────────┘

  ---
  2. Center of gravity — _compute_cog

  For each timepoint: finds the median voxel position of all non-zero
  segmentation labels, converts to RAS coordinates, saves a translation matrix
  T_cog (.npy). This centers images before pairwise registration.

  ---
  3. Initialize pairwise graph — _init_graph

  For every pair of timepoints:
  - Loads SynthSeg segmentation centroids (landmark positions in RAS space).
  - Applies T_cog centering.
  - Runs a closed-form SVD-based rigid registration (_register_timepoints) —
  equivalent to the Kabsch algorithm — to find the rotation + translation
  mapping one timepoint's centroids to another's.
  - Saves each pairwise affine as <tp_ref>_to_<tp_flo>.npy.

  ---
  4. Solve global graph — _solve_graph

  Combines all K = N(N−1)/2 pairwise transforms into globally consistent
  per-timepoint transforms:
  - init_st2_lineal: converts each pairwise rigid matrix to its Lie algebra
  (log-space) representation — extracts rotation vector and log-translation (6
  DoF per pair).
  - st2_lineal_pytorch: fits an InstanceRigidModelLOG using LBFGS with L1 or L2
  cost over all pairwise log-transforms. For N=2, closed-form; for N>2,
  iterative optimization (30 epochs, patience=3).
  - Outputs one 4×4 affine per timepoint (raw-to-template space), saved to
  uslr-lin/.

  ---
  5. Build subject template space — _create_subject_space

  - Computes a bounding box template that encompasses all registered timepoints
  (using dilated brain masks).
  - Rescales to a 192³ network space.
  - Resamples each timepoint's image and segmentation into this common space
  (with Gaussian anti-aliasing).
  - Creates the template image as the voxel-wise median across timepoints.
  - Creates the template segmentation by majority vote (argmax of summed one-hot
   encodings).
  - Saves per-timepoint resampled images/segs and the subject-level template.

  ---
  6. Estimate eTIV — _compute_etiv

  - Reprojects each timepoint's brain mask into template space and averages
  them.
  - Saves sub-<id>_T1wetiv.npy (sum of the averaged mask = estimated total
  intracranial volume in voxels).

  ---
  7. Register to MNI (optional) — _register_to_MNI

  Only if --reg_MNI:
  - Computes centroids of the subject template segmentation and the MNI152 atlas
   segmentation.
  - Fits a linear affine M_sbj (subject → MNI) via the same centroid-matching
  approach.
  - Applies the full chain M_sbj⁻¹ @ aff⁻¹ to each timepoint's image and
  segmentation and resamples to MNI space.

  ---
  Data Flow Summary

  BIDS rawdata (T1w)
      ↓ [SynthSeg — preproc pipeline, prior step]
  Segmentations + bias-corrected images (preproc/)
      ↓ [linear_registration.py]
  Per-timepoint affines (.npy)  →  Resampled images/segs in subject space
                                            ↓
                                Subject template (image + seg + mask)
                                            ↓
                                eTIV estimate (.npy)
                                            ↓ [if --reg_MNI]
                                MNI-space images/segs per timepoint
